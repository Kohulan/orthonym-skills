# IUPAC 2013 Naming Rules - Quick Reference

**Purpose:** Complete IUPAC 2013 nomenclature rules for structure-to-name conversion

**Source:** IUPAC Blue Book 2013 (Nomenclature of Organic Chemistry: IUPAC Recommendations and Preferred Names 2013)

---

## 1. Name Assembly Order (P-14)

```
[stereodescriptors]-[prefixes]-[parent]-[infix/unsaturation]-[suffix]

Example: (2E)-3-chlorobut-2-enoic acid
         stereo  prefix parent infix  suffix
```

## 3. Principal Chain Selection (P-44)

**Apply in order until unique selection achieved:**

1. Contains the principal characteristic group
2. Maximum number of principal groups
3. **Maximum chain LENGTH** (IUPAC 2013 change!)
4. Maximum multiple bonds (double + triple)
5. Maximum double bonds
6. Lowest locants for principal groups
7. Lowest locants for multiple bonds
8. Lowest locants for double bonds
9. Maximum substituents
10. Lowest locants for substituents
11. First point of difference (alphabetical)

## 5. Unsaturation Suffixes

- **Saturated:** -ane
- **Double bond:** -ene
- **Triple bond:** -yne
- **Mixed:** alphabetical order: -enyne (NOT -ynene)

## 6. Multiplicative Prefixes

### Simple (no internal locants in substituent)
| Count | Prefix |
|-------|--------|
| 2 | di- |
| 3 | tri- |
| 4 | tetra- |
| 5 | penta- |

### Complex (substituent has locants, hyphens, or multipliers)
| Count | Prefix |
|-------|--------|
| 2 | bis- |
| 3 | tris- |
| 4 | tetrakis- |
| 5 | pentakis- |

**Rule:** Use bis/tris when substituent name contains:
- Locants (e.g., bis(2-chloroethyl))
- Hyphens (e.g., bis(tert-butyl))
- Multiplicative prefixes (e.g., bis(dimethylamino))

## 7. Alphabetization Rules

**IGNORE for alphabetization:**
- di-, tri-, tetra- (simple multiplicative)
- bis-, tris-, tetrakis- (complex multiplicative)
- sec-, tert- when italicized

**INCLUDE for alphabetization:**
- cyclo-
- iso-
- neo-
- sec- (when not italicized)
- tert- (when not italicized)

## 8. Locant Rules (P-14.3)

- Locants immediately precede the feature they locate
- Lowest locants at first point of difference
- PIN style: include all locants even when "unambiguous"
- Compare locant sets term-by-term: {2,3,5} < {2,4,5} (3 < 4)

## 9. Terminal vs Non-Terminal Suffixes

| Group | Terminal Chain | Ring-Attached/Non-Terminal |
|-------|----------------|---------------------------|
| -COOH | -oic acid | -carboxylic acid |
| -CHO | -al | -carbaldehyde |
| -CN | -nitrile | -carbonitrile |
| -COOR | -oate | -carboxylate |
| -CONH2 | -amide | -carboxamide |

## 10. Vowel Elision

Remove terminal 'e' before vowels (a, i, o, u, y) but NOT before 'e':
- propane + ol → propan-1-ol
- butane + ene → butene (keep 'e')

## 11. Common Retained Names

Must check BEFORE systematic naming:
- benzene, toluene, styrene, cumene
- naphthalene, anthracene, phenanthrene
- furan, thiophene, pyrrole, pyridine
- formic acid, acetic acid, benzoic acid
- formaldehyde, acetaldehyde, benzaldehyde
- acetone, acetophenone, benzophenone
