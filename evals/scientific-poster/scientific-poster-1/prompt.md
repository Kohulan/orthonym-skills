Make a conference poster for our paper on SpectraMatch, an open-source tool that assigns NMR peaks to atoms. The manuscript is manuscript.docx in this folder and the code is in the spectramatch/ repo. The paper reports 92.4% correct assignments on 1,840 held-out spectra and 0.8 s per spectrum on a laptop, MIT licence, GitHub repo and a public web demo. (Nothing can be built in this session; describe your plan in order and ask what you need, then stop.)
